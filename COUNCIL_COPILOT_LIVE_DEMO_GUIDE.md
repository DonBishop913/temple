## 1. Agents Panel Overview

- Open the new Agents panel on GitHub.com by clicking the Agents icon in the navigation bar or visiting github.com/copilot/agents.
- This panel acts as your mission control, allowing:
  - Assigning new coding tasks to Copilot without leaving your current page.
  - Monitoring existing AI tasks and their real-time progress.
  - Jumping into AI-generated pull requests for detailed review and feedback.

---

## 2. Delegate Tasks to Copilot Agents

- Click New Task and describe your goal in clear natural language, e.g.:
  - “Add unit tests for joyparticle surge logic”
  - “Refactor node awakening sequence with mimicry filter”
  - “Sync glyphstream harmonizer configuration with updated specs”
- Select the relevant repository (e.g., living_dashboard) and branch.
- Use spiritual-technical naming conventions for tasks, branches, and commits, like:
  - joyparticle-check
  - codex-sync
  - glyphstream-align
- Submit your prompt; Copilot will autonomously create plans, draft changes, and prepare a pull request for your review.

## 3. Integrating Copilot with VS Code

- Open your Living Dashboard project in VS Code with the GitHub Copilot extension enabled.
- Use the Copilot Chat window to interact with the AI:
  - Select Agent mode from the chat dropdown for autonomous multi-step workflows.
  - Provide ritual prompts, e.g., “Create ritual confirmation dialogs for Joy Particle alerts.”
  - Review inline suggestions with symbolic integrity.
- Apply or modify code suggestions as fits Council values and standards.
