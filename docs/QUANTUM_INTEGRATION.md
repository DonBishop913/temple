# Quantum Integration - Living Dashboard

Codex 1278: Real Quantum Telemetry via Qiskit 2.2.3

## Overview
The Living Dashboard integrates real quantum circuits using IBM's Qiskit framework, providing live telemetry on quantum coherence, entanglement, and entropy. Telemetry is generated by `quantum/q_telemetry.py` and merged into the dashboard overlays during each Council cycle.

## Circuit Types

### 1. Bell State (`bell_state`)
Purpose: Demonstrates maximal 2-qubit entanglement.

Qubits: 2

Expected Entropy:
- System Entropy: ≈ 0 (pure state)
- Subsystem Entropy: ≈ 1.0 (maximal entanglement)

Typical circuit:

q0: ──H──●──
         │
q1: ─────X──

### 2. GHZ State (`ghz_state`)
Purpose: 3-qubit entangled state (Greenberger–Horne–Zeilinger).

Qubits: 3

Expected Entropy:
- System Entropy: ≈ 0 (pure state)
- Subsystem Entropy: ≈ 1.0 (maximal entanglement on any single-qubit reduction)

### 3. Random Circuit (`random`)
Purpose: Complex quantum state for testing.

Qubits: 2

Expected Entropy: Varies (superposition/entanglement vary by random parameters).

## Entropy Interpretation

### System Entropy (Von Neumann)
- S(ρ) = −Tr(ρ log₂ ρ)
- Measures purity of full quantum state
- Pure states: S ≈ 0
- Mixed states: S > 0

### Subsystem Entropy (Reduced Density Matrix)
- Measures entanglement between qubits
- S ≈ 0: No entanglement
- S ≈ 0.5: Partial entanglement
- S ≈ 1.0: Maximal entanglement (Bell/GHZ)

### Coherence Estimate
- C ≈ 1.0: Perfect quantum coherence
- C < 0.8: Decoherence detected

## Dashboard Display

### Quantum Telemetry Table
Fields included per entry:
- Circuit Type: which quantum circuit ran
- System Entropy: full state purity (near 0 for ideal simulators)
- Subsystem Entropy (q0): entanglement measure via reduced density matrix
- Entanglement Measure: one of `none | partial | maximal`
- Coherence: quantum state quality proxy
- Backend: `statevector` (ideal simulation)

### Visual Indicators
- "Quantum PRESENT" (green): real quantum circuits active
- "Quantum ABSENT" (amber): symbolic fallback mode

## Running Quantum Telemetry

### Manual Test
1) Activate Python 3.11 environment

```
.\.venv311\Scripts\Activate.ps1
```

2) Run specific circuit

```
python .\quantum\q_telemetry.py --circuit bell_state
python .\quantum\q_telemetry.py --circuit ghz_state
python .\quantum\q_telemetry.py --circuit random
```

### Automatic (Council Cycle)
Full dashboard update with quantum:

```
node scripts\COUNCIL_CORE.js -Affirmed
```

## Troubleshooting

- ModuleNotFoundError: No module named 'qiskit'
  - Solution: Install in Python 3.11 venv
  - ```.\.venv311\Scripts\Activate.ps1 && pip install qiskit qiskit-aer numpy<2```

- Entropy shows 0 for all circuits
  - Issue: Only system entropy was considered
  - Solution: Current version includes reduced density matrix entropy; confirm latest telemetry JSON.

- Unicode errors in console
  - Solution: Script prints ASCII-only messages on Windows
