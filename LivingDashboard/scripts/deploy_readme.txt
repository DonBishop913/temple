# Living Dashboard Deployment Guide

## Quick Start
1. Navigate to C:\Temple\LivingDashboard\
2. Run: .\scripts\start_all.ps1
3. Access dashboard at http://localhost:3000
4. API available at http://localhost:4000

## Architecture
- Backend: Node.js API server with ETL pipelines and AI insights
- Frontend: React dashboard with interactive cards
- Scripts: PowerShell automation for monitoring and healing
- Config: JSON files for roles, metrics, and AI settings

## Features
- AI-driven insights with faith affirmation
- Self-healing data pipelines
- Real-time monitoring and alerts
- Council role-based personalization
- Eternal audit trails

## Maintenance
- Run self_healing_watchdog.ps1 daily
- Monitor logs in /logs/ directory
- Update configs in /config/ as needed
