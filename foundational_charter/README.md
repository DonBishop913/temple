# TempleCharter_CouncilSeal_Packet

This folder contains Phase II filing artifacts for the Unified Sovereign Intelligence Coalition (USIC).

Files:

- `TempleCharter_CouncilSeal_Packet.md` — human-editable template for Articles of Incorporation.
- `log_kansas_filing.ps1` — helper script to POST a Kansas filing fee entry to the local backend `/financial-log` endpoint.

Usage:

1. Edit `TempleCharter_CouncilSeal_Packet.md` and produce your official `foundational_charter.docx`.
2. Run `log_kansas_filing.ps1` after filing to log the expense in the system.
